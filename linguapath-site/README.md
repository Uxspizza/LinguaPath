# LinguaPath — многостраничный образовательный сайт

### Главная страница

Главная страница намеренно сделана без иллюстрации в верхнем блоке: область с рисунком полностью удалена, текстовый блок занимает доступную ширину.

Адаптивный статический сайт-справочник по английскому языку. Сделан на HTML, CSS и JavaScript без внешних библиотек и сборки.

## Как запустить

**Windows:** распакуйте ZIP и дважды нажмите `start.bat`. Откроется окно сервера, а сайт запустится в браузере автоматически. Чтобы остановить сервер, нажмите `Ctrl+C` в окне запуска. Требуется Python 3.

**macOS:** откройте `start.command` (при необходимости разрешите запуск) либо выполните `python3 start.py` в терминале из папки сайта.

**Linux:** выполните `python3 start.py` в терминале из папки сайта.

Запускающий скрипт выберет свободный порт в диапазоне 8000–8010 и автоматически откроет страницу в браузере.

**Альтернатива:** откройте `index.html` напрямую или запустите `python -m http.server 8000`.

## Мобильная адаптация

Интерфейс адаптирован для телефонов, планшетов и настольных экранов. На узких экранах шапка переходит в компактную компоновку с доступным поиском и раскрывающимся меню; карточки, формы, текстовые статьи, тесты, словарь и мини-игра перестраиваются в удобные колонки. Для сенсорных экранов увеличены основные интерактивные области, поля форм используют безопасный для мобильных браузеров размер текста, а анимации учитывают системную настройку уменьшения движения.

Рекомендуемые контрольные ширины при проверке: 320, 360, 390, 430, 768, 844, 1024, 1440 и 1920 пикселей.

## Страницы

- `index.html` — главная, возрастные группы и слово дня
- `catalog.html` — каталог материалов
- `grammar.html` — грамматика и справочные темы
- `vocabulary.html` — словарь с поиском, фильтрацией и произношением
- `speaking.html` — разговорные выражения
- `writing.html` — шаблоны письма
- `topics.html` — тексты для чтения
- `tests.html`, `quiz.html` — тесты и результаты
- `games.html`, `game-word.html` — обучающие игры и рабочая игра «Собери слово»
- `age.html?group=children|teens|students|adults` — возрастные подборки
- `article.html?id=present-simple` — отдельные статьи
- `search.html?q=...` — поиск по сайту
- `login.html`, `profile.html` — локальный демонстрационный профиль
- `admin.html` — локальное добавление карточек материалов
- `about.html`, `contact.html`, `privacy.html`, `404.html` — информационные страницы

## Функции, работающие в автономной версии

- Адаптивная навигация и переходы между страницами.
- Поиск по встроенному контенту и фильтрация каталога.
- Словарь с фильтром по уровню, избранным и синтезом произношения браузером (если поддерживается).
- Сохранение возрастной группы, локального профиля, избранного и результатов в `localStorage` браузера.
- Квиз из пяти вопросов с подсчётом результата и разбором ответов.
- Мини-игра по сборке английского слова с подсказкой, проверкой, очками и итогом.
- Локальное добавление карточек материалов через демонстрационную панель.

## Важные ограничения

Это **полноценный фронтенд-прототип**, но не серверный production-сервис. Данные профиля, избранного, результаты и материалы из панели администратора хранятся только в текущем браузере и не синхронизируются между пользователями или устройствами. Локальная панель администратора не имеет авторизации и не должна использоваться как защищённая CMS в публичном интернете. Форма контактов специально сообщает, что письмо не отправлено — backend для отправки не подключён.

Для публичного запуска потребуются серверная база данных, реальная авторизация, защищённая административная панель, серверная отправка формы, проверка прав доступа, резервное копирование, юридически проверенная политика конфиденциальности и проверка требований к обработке данных детей.

## Технологии

- HTML5
- CSS3 (адаптивный layout, CSS custom properties)
- Vanilla JavaScript
- `localStorage` для локального демонстрационного состояния
- Web Speech API для произношения, если поддерживается браузером
